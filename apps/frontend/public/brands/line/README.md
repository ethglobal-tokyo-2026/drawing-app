# LINE Login icon

`login-icon.png` is the unmodified `images/DeskTop/2x/44dp/line_88.png` from LINE's official login-button template. It includes the white speech bubble and its transparent margins.

- Template: https://vos.line-scdn.net/line-developers/docs/media/line-login/login-button/LINE_Login_Button_Image.zip
- Design guidance: https://developers.line.biz/en/docs/line-login/login-button/
- Usage guidelines: https://terms2.line.me/LINE_Developers_Guidelines_for_Login_Button

Keep its proportions, color, and margins. The sign-in button supplies LINE's green background.
