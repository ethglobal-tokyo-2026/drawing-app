# Layers Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Up to ten layers on the drawing screen: a layer column under the size rail, per-layer opacity, Lock transparent pixels, Clip to layer below, drag reorder, a selection flash and Pencil-hover magnification. Sealing, the kept drawing and the timelapse carry layers. Drawing stays lag-free.

**Architecture:**

- **Layer state.** A pure layer model (`LayerState`, changed only by `LayerStep`s) sits beside the ops, and both go in one undo history.
- **Ink.** Each layer's ink is a sheet-sized offscreen canvas. Three canvases show the sheet, `below`, current and `above`, plus a wet-stroke canvas for the live brush stroke. One compositing function serves the display, the fill's read, the seal and the timelapse.
- **Undo.** Checkpoints are copy-on-write per layer, under a memory budget.

**Tech stack:** React 19, TypeScript, Canvas 2D, Vitest, Playwright (Chromium and WebKit), Hono with Zod (API), Drizzle with SQLite (db).

**Spec:** `docs/superpowers/specs/2026-10-09-layers-design.md`. Read it first; this plan doesn't repeat its decisions.

**Code in this plan:** the code blocks are the contracts lanes share (types, signatures, schemas). Bodies follow the spec and the behavior lists here. Every task names its tests and the edit that should turn each one red.

```ts
// canvas/ops.ts
/** The drawing tools. Brush and eraser make strokes; fill makes fills. */
export type Tool = "brush" | "eraser" | "fill";
/** Numbers per point in `StrokeOp.pts`: x, y, width, t. */
export const STRIDE = 4;
/** A layer's number: printed on its chip, kept for life, never reused on a sheet. */
export type LayerId = number;
export interface StrokeOp {
  tool: "brush" | "eraser";
  layer: LayerId;
  color: string;
  pts: number[];
  T: number;
}
export interface FillOp {
  tool: "fill";
  layer: LayerId;
  x: number;
  y: number;
  color: string;
  gap: number;
  T: number;
}
/** Every mark on a layer is one op. */
export type Op = StrokeOp | FillOp;
/** A change to the layers, one undo step each; `tool` names the change. */
export type LayerStep =
  | { tool: "add"; layer: LayerId; at: number; T: number } // at: its index from the back
  | { tool: "delete"; layer: LayerId; T: number }
  | { tool: "move"; layer: LayerId; to: number; T: number }
  | { tool: "opacity"; layer: LayerId; opacity: number; T: number } // 0–100, whole numbers
  | { tool: "lock"; layer: LayerId; on: boolean; T: number }
  | { tool: "clip"; layer: LayerId; on: boolean; T: number }
  | { tool: "clear"; layer: LayerId; T: number };
export type Step = Op | LayerStep;
export const isOp = (step: Step): step is Op =>
  step.tool === "brush" || step.tool === "eraser" || step.tool === "fill";
```

```ts
// layers/layerState.ts
export { MAX_LAYERS } from "@drawing-app/api/client"; // the API bounds a timelapse's layers by it too
export interface Layer {
  id: LayerId;
  opacity: number;
  locked: boolean;
  clipped: boolean;
}
/** Back to front. `nextId` is one more than the highest number the sheet has used. */
export interface LayerState {
  layers: readonly Layer[];
  nextId: LayerId;
}
export const FIRST_LAYERS: LayerState; // one layer, 1, at 100%
export function applyLayerStep(state: LayerState, step: LayerStep): LayerState; // pure; "clear" returns state
/** The nearest unclipped layer below a clipped one; null when it isn't clipped or nothing is below. */
export function baseOf(state: LayerState, id: LayerId): Layer | null;
export const isHidden = (layer: Layer): boolean => layer.opacity === 0;
export function indexOf(state: LayerState, id: LayerId): number;
/** Which layers hold ink after `steps`, from a blank sheet: an op inks its layer; clear and delete empty it. */
export function inkedAfter(steps: readonly Step[]): ReadonlySet<LayerId>;
/** Where a timelapse starts: just past the last step after which no layer had ink. */
export function timelapseStart(steps: readonly Step[]): number;
/** The state at `index` steps, from FIRST_LAYERS. */
export function stateAt(steps: readonly Step[], index: number): LayerState;
```

### Task 2.4: Timelapse v2: format, API and migration (lane T1)

**Files:**

  - `decodeTimelapse` reads v2 into `{ ink, place, density, layers: LayerState, steps: Step[] }`.

```ts
const layerId = z.number().int().min(1);
const at = z.number().int().nonnegative();
export const timelapseV2Schema = z.object({
  v: z.literal(2),
  ink: z.tuple([z.number().positive(), z.number().positive()]),
  place: z.tuple([z.number(), z.number(), z.number().positive(), z.number().positive()]),
  density: z.number().positive(),
  /** The layers where the timelapse starts, back to front: number, opacity, locked, clipped. */
  layers: z
    .array(z.tuple([layerId, z.number().int().min(0).max(100), z.boolean(), z.boolean()]))
    .min(1)
    .max(MAX_LAYERS),
  ops: z.array(
    z.union([
      z.tuple([z.enum(["brush", "eraser"]), layerId, z.string(), z.number(), strokePoints]),
      z.tuple([
        z.literal("fill"),
        layerId,
        z.string(),
        z.number(),
        z.number(),
        z.number(),
        z.number().nonnegative(),
      ]),
      z.tuple([z.literal("clear"), layerId, z.number()]),
      z.tuple([z.literal("add"), layerId, z.number(), at]),
      z.tuple([z.literal("delete"), layerId, z.number()]),
      z.tuple([z.literal("move"), layerId, z.number(), at]),
      z.tuple([z.literal("opacity"), layerId, z.number(), z.number().int().min(0).max(100)]),
      z.tuple([z.literal("lock"), layerId, z.number(), z.boolean()]),
      z.tuple([z.literal("clip"), layerId, z.number(), z.boolean()]),
    ]),
  ),
});
export type TimelapseV2 = z.infer<typeof timelapseV2Schema>;
```

- The frontend's encode → decode round-trips multi-layer steps.
- `MAX_LAYERS + 1` layers are refused.
