RANKED SPIKE CAUSES
1. The light's writes restyle and repaint every lit element (measured: tilt, mouse).
   apps/frontend/src/stickers/light.ts:103-118 setOnResins writes --lx/--ly inline on every
   .live-resin, .sticker-foil and .sticker-crease (about 3 per sticker) each beat (BEAT_MS = 45,
   light.ts:22); readers: live-resin.css:56-58 (translate from var(), with a 280 ms transition
   restarted on each write, over the sway animation), sticker-foil.css:133-134, 203 (--foil-slide on
   a repeating-linear-gradient band: a repaint), 260, sticker-crease.css:7-16 (hypot/calc chains).
   Simplest fix to try first: a slower beat while tilting (the JS glide and the CSS transition already
   smooth it, two smoothing layers), and move the foil sheen with translate rather than a value the
   gradient reads, so a write recomposites instead of repainting. A/B with measure.mjs light-tilt.
2. The tilt's sheen sweep (suspected, not separated): light.ts:80-86 sweepVisible reads every
   resin's getBoundingClientRect and starts one element.animate per visible resin in the same event
   (light.ts:183), when a tilt passes 9 degrees. Fix: start the sweeps in the next rAF, after the
   light's write, or stagger them.
3. Boot: spec and rim are fetched and decoded for nothing (measured: 23% of image bytes, 34% of
   image requests, 28% of image decode). boardComplete.ts:78 assemblyOf waits on png, mask, spec, rim.
   Fix: drop spec and rim from assemblyOf, and from StickerUrls if nothing else shows them.
4. Boot: each mask is fetched twice and decoded twice (measured: 2 requests per sticker, and a
   re-download of one copy on every reload in Chromium). boardComplete.ts:54-59 decodeImage loads
   without crossOrigin, while the CSS mask (StickerFigure.tsx:90 --m, useBoardGestures.ts:274) is a
   CORS fetch; the API sends Vary: Origin on images (source not located). Fix: drop Vary: Origin from
   same-origin image responses, or set img.crossOrigin = "anonymous" in decodeImage so the warm-up
   matches the mask's request. Check production's headers through Fastly (not checked).
5. Boot render: a 428-467 ms React render task with 24 stickers (measured, in React's development
   build at 4x; production's share unverified).
6. Drag pickup and drop frames, 83-183 ms (measured, not attributed; suspected: the pickup sheen,
   the drop's re-render and placement save).
