# Independent endpoint evaluator review

Read-only review of the authoritative `apps/frontend/src/sticker-creation/canvas/post-correction/evaluator.ts`, its research tests, addressed assembly, and `spikes/post-evaluator/native_oracle.py`. No arithmetic, ABI, configuration-layout, or branch-order discrepancy was found in the finite supported domain examined.

- The native harness correctly widens retained binary32 scalars into record offsets `+10..40` and exports node bits 12/13 into record flags `+50`. Synthetic evaluator fields and response pointers use the offsets read by the extracted functions. It does not obtain the missing brush configuration from the earlier capture.
- `0x1024c497c` compares main response flags to exactly one, uses node bit12 to bypass only the main response/random multiplier, scales by retained scalar5, and clamps before secondary/adjustment operations. The code preserves that sequence, including the secondary branch's multiplication of the primary by 0.7.
- `0x1024aff24` receives random-enable zero, so the omitted generator branch cannot execute. Scalar inputs 0/1/2 and 4, binary32 second-curve span subtraction, and every fused factor match the code.
- Adjustment mode comparison is unsigned. Only modes 1–3 read the three table entries; other nonzero modes use zero. The code's explicit uint32 validation and selected amounts follow that behavior. The brush-bit4 operation precedes the fused subtraction.
- `0x10359b494` keeps the native root order and returns a duplicated root near a zero discriminant. `0x10359cf18` accepts `[0,1)` and uses the first qualifying root in the caller. The code retains these choices and the exact nested fused Bernstein evaluation.
- `0x10359de0c` selects local controls using strict/non-strict x comparisons and separately rounded adjacent midpoints. `0x10219455c` checks the nearly vertical interval before its fused extrapolating line formula. The implementation matches those comparisons and does not clamp input to `[0,1]`.

The 680 saved native cases are independent of TypeScript output: the harness relocates original instruction bodies and constant pages, verifies emitted instructions/targets, and supplies only a local stack guard. Synthetic configuration/control restrictions and the absence of a captured full evaluator remain explicit. Constructor defaults and the half-size application profile must not be described as the unknown captured brush configuration. This review does not establish universal host `sqrt` equivalence outside the existing finite, FPCR-zero arithmetic scope.
